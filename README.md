# Cat GateKeeper - 猫咪休息管家

一款帮助用户定时休息的 Chrome 浏览器插件，通过可爱的猫咪动画监督你休息，保护眼睛健康，提升工作效率。

## 🌟 功能特色

- ⏰ **智能计时**：可自定义工作时长和休息时长（分钟为单位）
- 🐱 **交互式猫咪动画**：休息时间可爱的橘猫会走到屏幕中央陪伴你休息
- 🎬 **丰富的动画效果**：猫咪呼吸、眨眼、摇尾巴、耳朵抖动等生动动画
- 🖼️ **自定义背景**：支持上传自己喜欢的图片作为休息背景
- 🔄 **自动循环**：休息结束后猫咪离开，自动开始下一轮工作计时
- 💾 **本地存储**：所有设置本地保存，保护隐私安全
- 🎨 **现代UI设计**：毛玻璃效果、渐变色彩、流畅的动画过渡

## 📦 安装方法

### 方法一：开发者模式安装
1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的 **"开发者模式"** 开关
3. 点击 **"加载已解压的扩展程序"** 按钮
4. 选择项目目录 `webCat`
5. 插件安装成功！工具栏会出现猫咪图标

## 📖 使用说明

### 开启插件
1. 点击 Chrome 工具栏的猫咪图标
2. 在弹出窗口中点击开关按钮启用插件

### 设置参数
- **工作时长**：设置每次连续工作的时间（分钟），默认 60 分钟，不能为 0 分钟
- **休息时长**：设置每次休息的时间（分钟），默认 5 分钟，最多 10 分钟
- **自定义背景**：（可选）上传喜欢的图片作为休息背景，支持 JPG、PNG、GIF 格式

### 保存设置
1. 调整好参数后点击 **"保存设置"** 按钮
2. 设置成功后会显示提示信息
3. 计时器自动开始运行

### 休息时间
- 到达设定的工作时长后，浏览器会显示全屏休息遮罩层
- 可爱的橘猫会从屏幕左侧走进来，在中央坐下陪伴你休息
- 猫咪会有呼吸、眨眼、摇尾巴、耳朵抖动等生动动画
- 遮罩层显示：倒计时、休息小贴士
- 休息结束时，猫咪会从右侧离开屏幕，显示"休息完成！喵~"提示
- 遮罩层自动隐藏，开始下一轮工作计时

## 🔧 技术栈

- **Manifest Version**: 3（Chrome 最新扩展标准）
- **前端技术**: HTML5, CSS3, JavaScript (ES6+)
- **动画技术**: 
  - SVG 内置动画（呼吸、眨眼、摇尾巴、耳朵抖动）
  - CSS Keyframes 动画（猫咪走进走出、呼吸律动）
  - JavaScript 动画控制
- **Chrome API**:
  - `chrome.storage` - 本地数据存储
  - `chrome.alarms` - 定时任务
  - `chrome.tabs` - 标签页管理
  - `chrome.runtime` - 扩展通信

## ⚙️ 配置说明

### manifest.json 权限说明
```json
"permissions": [
  "storage",    // 存储用户设置和图片
  "alarms",     // 定时任务
  "tabs",       // 标签页通信
  "activeTab"   // 当前标签页操作
]
```

### 默认配置
| 配置项 | 默认值 | 范围 |
|--------|--------|------|
| 工作时长 | 60 分钟 | ≥ 1 分钟 |
| 休息时长 | 5 分钟 | 1-10 分钟 |
| 自定义图片 | 无（使用默认猫咪动图背景） | JPG/PNG/GIF，≤5MB |

## 🎯 核心功能实现

### 计时器系统
- 使用 `chrome.alarms` API 实现跨会话的持久化计时
- 工作计时结束触发休息提醒
- 休息计时结束自动恢复工作计时

### 猫咪动画系统
- **走进动画**：猫咪从屏幕左侧跳跃式走进（2秒）
- **休息动画**：猫咪在中央有呼吸律动（3秒循环）
- **SVG内置动画**：
  - 眼睛眨动（4秒/4.5秒不同步，更自然）
  - 耳朵抖动（3秒/3.5秒不同步）
  - 尾巴摇摆（2秒循环）
  - 胡须微动（2.5秒/2.8秒不同步）
- **走出动画**：猫咪从屏幕右侧跳跃式离开（2秒）

### 遮罩层系统
- Content Script 注入到所有页面
- 全屏固定定位，z-index: 999999
- 半透明渐变背景 + 用户自定义背景图片
- 毛玻璃效果容器
- 流畅的入场/退场动画
- 休息完成时的特效文字

### 数据存储
- 所有设置通过 `chrome.storage.local` 持久化
- 图片以 base64 格式存储
- 开关状态、计时器配置自动保存

## 🐛 常见问题

**Q: 为什么插件不计时了？**
A: 请检查：
1. 插件是否已启用
2. 是否保存了有效设置（工作时长不能为0）
3. Chrome 浏览器是否在运行

**Q: 猫咪动画不显示？**
A: 请确认：
1. 插件是否正确加载（检查 `chrome://extensions/`）
2. 是否是 Chrome 内部页面（如 `chrome://extensions/` 不支持注入）
3. 尝试刷新页面

**Q: 上传的图片不显示？**
A: 请确认：
1. 图片格式是否支持（JPG/PNG/GIF）
2. 图片大小是否超过 5MB
3. 保存设置是否成功

**Q: 遮罩层在某些页面不显示？**
A: Content Script 默认会注入到所有 `http://` 和 `https://` 页面，但不会注入到：
- Chrome 内部页面（如 `chrome://extensions/`）
- 某些特殊的 Chrome Web Store 页面
- 浏览器设置页面
