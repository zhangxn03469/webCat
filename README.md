# Cat GateKeeper

一款可爱的Chrome浏览器定时休息插件，帮助用户在长时间工作后定时休息，保护眼睛健康。

## 功能特性

### 🐱 可爱的交互体验
- **全页面小猫走动**：休息时间，多只可爱的小猫会在屏幕上随机走动
- **睡眠区域**：屏幕底部有一个小猫睡眠区，小猫们在那里打盹
- **粒子特效**：小猫走过的地方会留下彩色粒子

### ⏰ 智能定时提醒
- **自定义工作时长**：灵活设置工作时间（分钟为单位）
- **自定义休息时长**：设置1-10分钟的休息时间
- **自动循环**：休息结束后自动开始下一轮工作计时

### 🎨 个性化设置
- **自定义背景图**：可以上传自己喜欢的图片作为休息界面背景
- **优雅的遮罩层**：休息时显示优雅的全屏遮罩层，提醒用户休息

## 安装方法

### 开发者模式安装（推荐）

1. **下载源码**
   - 将项目文件下载到本地任意目录

2. **打开Chrome扩展管理页面**
   - 打开Chrome浏览器
   - 在地址栏输入 `chrome://extensions/` 并回车
   - 或者通过菜单：右上角三个点 → 扩展程序 → 管理扩展程序

3. **开启开发者模式**
   - 在扩展管理页面右上角，开启"开发者模式"开关

4. **加载插件**
   - 点击左上角的"加载已解压的扩展程序"按钮
   - 选择下载的 `webCat` 文件夹
   - 点击"选择文件夹"

5. **安装完成**
   - 插件图标会出现在浏览器右上角工具栏中

## 使用说明

### 开启插件

1. 点击浏览器右上角的插件图标
2. 点击开关按钮开启插件
3. 设置面板会展开，显示可配置选项

### 设置参数

1. **工作时长**
   - 输入工作时间（分钟为单位）
   - 默认值：60分钟
   - 最小值：1分钟（不能为0）

2. **休息时长**
   - 输入休息时间（分钟为单位）
   - 默认值：5分钟
   - 范围：1-10分钟

3. **自定义背景图（可选）**
   - 点击上传区域或拖拽图片到此处
   - 支持格式：JPG、PNG、GIF
   - 最大大小：5MB

4. **保存设置**
   - 点击"保存设置"按钮
   - 插件会立即开始计时

### 休息体验

当工作时间结束时：

1. **遮罩层出现**：全屏显示优雅的休息界面
2. **小猫走动**：多只小猫在屏幕上随机走动
3. **倒计时显示**：显示剩余休息时间
4. **休息提示**：提供护眼小建议

休息结束后：

1. **自动隐藏**：遮罩层自动隐藏
2. **自动计时**：下一轮工作计时自动开始
3. **无缝循环**：无需手动操作，自动循环

### 关闭插件

1. 点击插件图标
2. 点击开关按钮关闭插件
3. 所有计时会停止

## 技术实现

### 核心技术栈
- **HTML5**：页面结构
- **CSS3**：样式设计、动画效果
- **JavaScript (ES6+)**：业务逻辑
- **Chrome Extensions API**：插件核心功能

### 关键API
- `chrome.alarms`：定时任务管理
- `chrome.storage`：本地数据存储
- `chrome.tabs`：标签页管理
- `chrome.runtime`：插件运行时通信

### 动画实现
- **CSS Keyframes**：小猫呼吸动画、粒子浮动
- **requestAnimationFrame**：平滑的小猫移动动画
- **CSS Transform**：高效的元素位置更新

## 注意事项

1. **Chrome版本要求**：建议使用Chrome 88及以上版本
2. **权限说明**：插件需要以下权限：
   - `storage`：存储用户设置
   - `alarms`：定时提醒
   - `tabs`：标签页管理
   - `activeTab`：当前标签页访问

3. **图片限制**：自定义背景图最大5MB，仅支持JPG、PNG、GIF格式
4. **网络依赖**：小猫GIF图片来自Giphy CDN，需要网络连接才能正常显示

## 常见问题

**Q: 为什么小猫图片不显示？**
A: 请检查网络连接，小猫GIF图片需要从Giphy CDN加载。

**Q: 定时器不准时触发？**
A: Chrome的alarms API为了省电可能会有微小延迟，属于正常现象。

**Q: 可以同时在多个浏览器窗口使用吗？**
A: 可以，遮罩层会在所有打开的标签页中显示。

**Q: 如何重置所有设置？**
A: 在扩展管理页面点击"详情"，然后点击"重置扩展"即可。
